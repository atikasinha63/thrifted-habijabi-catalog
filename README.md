A lightweight, responsive digital lookbook and inventory tracker built for **Thrifted Habijabi** ([@thrifted.habijabi](https://www.instagram.com/thrifted.habijabi)), an online thrifted bag and vintage accessories shop based in Dhaka, Bangladesh.

---

## ✨ Key Features

- **Dynamic Category Filtering:** Filter curated drops by style (`All`, `Shoulder Bags`, `Totes`, `Crossbody`, `Y2K Vintage`) without page reloads.
- **Instant Search & Stock Toggle:** Real-time search bar paired with an interactive **"In Stock Only"** filter to hide sold-out pieces.
- **Condition & Authenticity Badges:** Clear grading metrics (Mint, Very Good, Vintage Patina) and transparent BDT (`৳`) pricing.
- **Direct Social Checkout:** One-click order triggers that link buyers directly to Instagram DMs (`@thrifted.habijabi`) with the item code ready to inquire.
- **Zero Dependencies:** Built with pure semantic HTML5, modern CSS Grid/Flexbox, and Vanilla JavaScript for instant loading on mobile data.
